# Python Fundamentals — Logic & Algorithms

This repository contains solved exercises developed during a **university course on Logic and Algorithms**, using Python as the primary programming language.

The main goal is to build strong problem-solving skills, understand core programming concepts, and apply algorithmic thinking in practice.

---

## Covered Topics

### Introduction to Logic and Algorithms
- Algorithm concepts
- Logical sequence of instructions
- Structured problem-solving

---

### Sequential Algorithms
- Variables and data types
- Input and output operations (`input` and `print`)
- Basic operations and assignments

---

### Decision Structures
- Conditional statements (`if`, `elif`, `else`)
- Logical and relational operators
- Flow control based on conditions

---

### Iteration Structures
- `while` loops
- `for` loops
- Flow control (`break` and `continue`)
- Input validation
- Counters and accumulators

---

### Functions
- Function definition (`def`)
- Parameters and arguments
- Return values (`return`)
- Code reusability

---

### Lists
- Indexed data structures
- Element manipulation
- Iteration techniques
- Built-in list methods

---

### Tuples
- Immutable data structures
- Element access
- Differences between lists and tuples
- Data grouping

---
